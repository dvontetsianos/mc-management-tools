1. Install Python

2. Create venv:
	python -m venv .venv

3. .venv has to be activated, either with running .venv\Scripts\activate or with VS Code it activates automatically once you open the App folder

4. Install requirements:
	pip install -r requirements.txt

5. Starting the Server in dev mode:

	backend: [uvicorn app.main:app --reload --host 0.0.0.0 --port 8000] in ../F&B_Assets

	frontend: [npm run dev -- --host 0.0.0.0 ] in ../F&B_Assets/frontend
